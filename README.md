# Thiranex-Cybersecurity-Internship
A Python-based cybersecurity tool that analyzes password resilience using Shannon/combinatorial entropy calculations, rule-based scoring, and common password dictionary checks.
# Task 1: Password Strength Analyzer

## Project Overview
This project is an interactive Python script developed as part of the **Thiranex Cybersecurity Internship**. It evaluates user-entered passwords against key security metrics to determine mathematical predictability, complexity, and susceptibility to dictionary/brute-force attacks.

## Key Features
- **Entropy Calculation:** Measures mathematical strength in bits based on character set pool size (lowercase, uppercase, numbers, and special symbols).
- **Dictionary Checking:** Screens inputs against known/compromised passwords (e.g., `admin`, `pass1234`).
- **Rule-Based Scoring:** Assigns a score (0–100) based on length and character set diversity.
- **Verdict & Feedback:** Provides a final categorization (`Weak`, `Moderate`, `Strong`, `Very Strong`).
